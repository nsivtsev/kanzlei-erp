# BL-045 — синхронизация карточки Mandant с папкой Drive

**Статус:** реализовано и проверено 13 октября 2026 в ветке `codex/drive-downloads` поверх BL-044; [отчёт приёмки](../reviews/2026-10-13-drive-form-sync-verification.md).

**Цель:** после создания/получения папки форма сохраняет реквизиты без ошибки удаления защищённой связи, не теряя несохранённых данных. Папка, созданная в другой вкладке, синхронизируется перед сохранением.

## Реализация

- Общая синхронизация только `kanzlei_drive_folder` через `frm.set_value` с `skip_dirty_trigger=true`; без reload/autosave и изменения modified.
- Применение после get/create/open; немедленная смена кнопки после создания, один запрос при двойном нажатии, успешная синхронизация при блокировке popup.
- Асинхронный before_save для существующего Customer с пустой связью: дождаться текущего создания, перечитать get_folder, синхронизировать до отправки. Без Suite/папки обычное сохранение; ошибка проверки отклоняет попытку и сохраняет данные формы.
- Привязка запросов к объекту документа, имени и активному маршруту. Поздние ответы не меняют другую карточку; пустые ответы не стирают известную папку. Ошибка старой операции не меняет глобальную валидацию новой формы.
- Существующие API и схема БД сохраняются. Строгая защита связи и timestamp conflicts остаются; параллельные create должны возвращать один root.

**Уточнение по приёмке:** реальная параллельная проверка воспроизвела MariaDB snapshot-конфликт 1020. Первичное чтение Customer выполняется с блокировкой и ограниченным повтором до любых storage-изменений; права перепроверяются после rollback. Контракт API и схема БД не изменены.

## Приёмка

Сначала красные клиентские регрессии, затем синхронизация. Node: dirty/clean, initial/create/reopen, two tabs, in-flight/double click, out-of-order replies, navigation/document replacement, popup/network/access errors, Suite absent/new form. Сервер: stale snapshot → sync → save, mapping clear/forge denied, modified conflict retained. HTTP: два параллельных staff create, один root в БД, настоящий Customer save и отказы. Браузер: изменённые реквизиты → create → save; две карточки → create в первой → save во второй. Полный Node/Kanzlei, assets и image CI с BL-044.
