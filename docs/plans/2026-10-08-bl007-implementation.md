# BL-007 — Управление Rückfragen

Утвержденный план: один самостоятельно решаемый вопрос — одна Task типа Question.
Ручная привязка Communication, отдельные состояния вопроса, одно внутреннее
напоминание исполнителю. Ожидание Mandant, стадия периода и комплектность остаются
ручными действиями. Отправка почты и Freigabe относятся к следующим этапам.

## Реализация

1. Расширить Task: основной исполнитель, Contact, пункт чек-листа (entry_key),
   приватный File, контекст операции, даты запроса/ответа/срока/напоминания,
   остаток вопроса, решение и серверные отметки. Добавить неизменяемую историю.
2. Добавить create_question(context_doctype, context_name, values),
   update_question(name, action, values, expected_modified), get_questions(filters,
   start, page_length). Блокировки: пакет → дополнение → Task; проверять права,
   версию, открытый контекст, ссылки и исполнителя. Защитить обычные сохранения,
   массовые действия, смену типа/контекста и копирование.
3. Состояния: Draft/Open, Waiting/Working, Answer Received/Pending Review,
   Resolved/Completed, Cancelled/Cancelled. Overdue не меняет состояние вопроса.
   Request требует адресата, даты, срока и Communication/описания. Response требует
   даты, содержания, полноты и остатка для частичного ответа. Resolve требует
   решения; cancel/reopen — причины. Reopen возвращает Draft с сохранением истории.
4. Подключить форму Task, списки периода/дополнения, создание из чек-листа с защитой
   повторных нажатий; добавить Desk Page Rückfragen с фильтрами, сводкой и
   пагинацией, ссылку рабочего меню. Перевести RU/DE. Общий список Task не менять.
5. Daily scheduler создает Alert без email, один раз на цикл напоминания; повторно
   проверяет состояние/дату/исполнителя/права под блокировкой. Ответ снимает дату,
   решение/отмена отключают напоминание, перенос даты/исполнителя дает новый цикл.
6. Старые вопросы не интерпретировать автоматически. Открытые инициализируются
   отдельным действием; закрытая история неизменна. Новые копии без старых событий,
   решений, переписки и напоминаний. Не выдавать права при назначении.

## Проверки

Полный цикл, частичный и повторный ответ, несколько вопросов на одно письмо,
решение без ответа, отмена/reopen, неизменность истории; закрытие пакета/дополнения;
доступ сотрудника/заместителя и отказы чужому Mandant/файлу/переписке; stale версии,
повторное создание, конкурентные напоминания; назначения/зависимости/Overdue;
legacy/copy. Целевые и полные Frappe тесты, миграция дважды, сборка, статический
анализ и браузерная приемка RU/DE на искусственном Mandant (выписка 16–30 сентября).
