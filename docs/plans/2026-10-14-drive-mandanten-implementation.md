# BL-047 — Mandanten внутри Drive

**Цель:** сотрудник находит доступного клиента и его папку внутри Drive, без заранее известной ссылки.

**Архитектура:** Customer остаётся источником клиентов и прав. Kanzlei предоставляет разрешённый список и контекст сущности через серверный hook; Vue-страница и навигация поставляются cumulative patch закреплённого Suite. Схема БД и существующие API создания/открытия папки сохраняются.

**Стек:** Frappe/ERPNext v16, Suite (закреплённый commit из suite.env), Vue 3, Frappe UI, Bench/Vitest/Node и Docker CI.

## Принятые решения

- Список, поиск по ID/названию, страницы по 50 записей; отображаются также клиенты без папки.
- Обновление при открытии, возврате во вкладку и кнопкой. Фонового опроса и постоянного клиентского кэша нет.
- Папка открывается в текущей вкладке; карточка ERP — в новой. Создание отдельным нажатием по текущим правам Customer.
- BL-047 и профильные сценарии BL-050 входят в этап. BL-048–049, полный BL-050 и production-выпуск отдельные.

## Последовательность реализации

1. **Серверный список и тесты.** Добавить list_mandanten с get_list + проверкой документных прав, поиска и пагинации только по читаемым записям. DocShare-only читателям данные Customer выдаются пакетно после проверки права; File проверяется пакетно. Некорректная связь даёт отдельную unavailable-строку без URL/создания.
2. **Контекст сущности.** Добавить провайдер drive_entity_navigation, читать сохранённый File marker и актуальный Customer. Suite вызывает hook только после проверки чтения; сервер обрезает крошки до корня клиента. Обычные файлы сохраняют прежний ответ.
3. **Vue-интерфейс.** Отдельная Mandanten-страница, Sidebar/BottomBar, поиск 300 мс, состояния и действия. Поколения запроса/сессии отклоняют поздние ответы; возврат обновляет даже при старом запросе в полёте. Корень крошек показывает актуальное имя Customer и не запускает переименование.
4. **Упаковка.** Сохранить точный предыдущий Suite patch как v4; расширить installer/Docker context и тесты clean/v1–v4 → current, повтора и атомарного отката. Не менять закреплённую версию Suite.
5. **Приёмка.** Профильные Bench/Vitest, Root Node, deployment, реальные HTTP/Socket.IO grant/revoke/ZIP и DE/RU Chrome desktop/mobile; сборки Suite/Kanzlei и полный CI образа. Только после этого обновить checkbox BL-047.

## Публичный контракт

`list_mandanten(search="", start=0, page_length=50)` возвращает `{rows, has_next, next_start}`. Строка: `customer`, `customer_name`, `customer_url`, `state` (`ready`, `missing`, `unavailable`), `folder`, `url`, `can_create`. Смещение относится только к читаемым записям, `next_start=null` на последней странице. Размер ограничен 1–100. Только текущий System User; пользователь без доступных Customer получает пустой результат, Guest/Website User — отказ.

`get_entity_with_permissions` дополнительно возвращает `mandant` только для разрешённой управляемой сущности: `{customer, customer_name, folder, customer_url}`. Контекст не выводится из клиентских полей или маршрута. Недоступный/повреждённый корень не возвращает контекст.
